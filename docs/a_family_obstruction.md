# `A(a,b)` 型の未解決部分

この文書では、初手分類のうち「観測上は勝ち手になっている初手」を
証明するために残っている構造を整理する。

## `A(a,b)` への帰着

黒の初手 `i` の後、白番から見た局面は

```text
A(i, N - i - 1) = WO(i) + WO(N - i - 1)
```

である。したがって、黒の初手 `i` が勝ち手であることは、この `A` 局面が
手番プレイヤー負けであることと同値である。

すでに証明済みの部分は次である。

- `A(n,n)` は手番プレイヤー負け。
- `A(n,n+1)` と `A(n+1,n)` は手番プレイヤー負け。

これにより、奇数盤面の中央初手、および偶数盤面の中央 2 マス付近の初手は
勝ち手であることが分かる。

## 1 手後に現れる 3-gap 型

`A(a,b)=WO(a)+WO(b)` で、片方の `WO(b)` に位置 `p` が打たれたとする。
右側の残り長さを

```text
r = b - p - 1
```

とおく。手番交代後、応手側から見える局面は

```text
WM(a) + WO(p) + MO(r)
```

である。ここで `WM(a)` は、触られていないもう一方の `WO(a)` が手番交代で
見え方を変えた成分である。

応手側がこの `WM(a)` の位置 `q` に打つと、次に相手へ渡る局面は

```text
WO(q) + OO(a - q - 1) + WM(p) + MO(r)
```

になる。

特に `q=r` と選べる場合は

```text
WO(r) + MO(r) + WM(p) + OO(p + a - b)
```

となる。前半 `WO(r)+MO(r)` は 9 族の負け型である。したがって、この自然な
応手が証明に使えるかどうかは、後半

```text
D_delta(p) = WM(p) + OO(p + delta),  delta = a - b
```

を負け型として扱えるかに依存する。

均衡型では `delta=0` なので `D_0(p)=WM(p)+OO(p)` となり、これは 9 族に
含まれる。近均衡型では `delta=-1` または左右対称な場合だけを処理すれば
よく、これも 9 族に戻る。

一方、`|a-b| >= 2` 以上に離れると、`D_delta` は 9 族だけでは閉じない。
ここが `A(a,b)` 全体を証明する際の主要な障害である。

## 差が大きい境界型

同じ 3-gap 局面に対して、応手位置を少し変えると、別の境界型が残る。
例えば応手を `q=r+1` とすると

```text
WO(r+1) + MO(r) + WM(p) + OO(p + a - b - 1)
```

となり、前半は 9 族に戻るが、後半はやはり差のある `D` 型である。

また、別の応手では

```text
WO(x+d) + MO(x)
```

のような境界型も現れる。計算済みの境界型グリッドでは、この族は差 `d` に
よって単純な負け族にはならない。例えば `WO(x+d)+MO(x)` は `d=0,1` では
負けが続くが、`d=2,3,4` では勝ちが続き、`d=5,6,11` などでは負けと勝ちが
混在する。

したがって、差が大きい場合を「境界型は常に負け」または「常に勝ち」と
みなす単純化は正しくない。証明には、どの境界型を相手に渡すのかを応手ごと
に制御する必要がある。

## 小さい例外と反例候補

計算範囲 `a+b <= 44` では、観測されている `N >= 20` の初手規則に反する
例は出ていない。

ただし、既知の負け手に対応する `A` の勝ち例を除くと、次の小さい例外が
存在する。

```text
A(3,6), A(3,11), A(4,7), A(4,8), A(4,14), A(6,9), A(7,11)
```

およびその左右対称である。これらはいずれも `a+b <= 18` に収まる。

この事実は、`N >= 20` で規則が安定する可能性を示しているが、証明ではない。
特に、差の大きい補助族に周期的または疎な例外がある場合、より大きい `N` で
同種の反例が再出現する可能性は残る。

## 補助族単体の観測

`D_delta(p)` を単独で見ると、負けが続くのは現在分かっている範囲では
`delta=-1,0` だけである。小さい範囲での厳密計算では、例えば次のように
なる。文字列は `p` を小さい順に並べた勝敗で、`L` が手番プレイヤー負け、
`W` が手番プレイヤー勝ちを表す。

```text
D_-1: LLLLLLLLLLL
D_0 : LLLLLLLLLLLL
D_1 : LWWWWWWWWWWW
D_3 : LWLLWLWWWWWW
D_5 : LWLLWLLWLLWL
```

境界型 `B_d(x)=WO(x+d)+MO(x)` も同様に単純ではない。

```text
B_0: LLLLLLLLLLLL
B_1: LLLLLLLLLLLL
B_2: WWWWWWWWWWWW
B_5: WLWWLWWWWLWW
B_6: WLLWLLWLLWLL
```

これらは証明ではなく、補助定理の候補を探すための観測である。
ただし、少なくとも「差のある 2-gap 型を丸ごと負け族として追加する」
方針は成立しないことを示している。

## 次の証明目標

次に必要なのは、`D_delta(p)=WM(p)+OO(p+delta)` を単独で分類することでは
ない。`D_delta` 単独には勝ち負けの混在があり得るためである。

必要なのは、3-gap 型

```text
WM(a) + WO(p) + MO(r)
```

について、各合法手に対して少なくとも 1 つの応手が、既知の負け型または
より小さい同型補助族へ落ちることを示す帰納構造である。

この補助族が閉じれば、`A(a,b)` の差が大きい場合も扱える可能性がある。
逆に、この補助族の中に無限に現れる勝ち例があれば、現在観測されている
`N >= 20` の規則に対する将来の反例候補になる。
