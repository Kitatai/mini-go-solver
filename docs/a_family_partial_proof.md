# `A(a,b)` 型の部分証明

この文書では、初手後に現れる

```text
A(a,b) = WO(a) + WO(b)
```

について、既存の 9 族負け定理だけで証明できる範囲をまとめる。

`A(a,b)` が手番プレイヤー負けであれば、その `A(a,b)` を相手に渡す初手は
先手勝ちである。

## 均衡型 `A(n,n)`

全ての `n >= 1` について、`A(n,n)` は手番プレイヤー負けである。

`n = 1,2` では合法手が存在しないか、直接確認できる。以下、合法手が
存在する場合を考える。

片方の `WO(n)` の位置 `p` に打たれたとする。合法性より
`1 <= p <= n - 2` である。`r = n - p - 1` とおく。

手番交代後、打たれた gap は

```text
WO(p) + MO(r)
```

になり、触られていないもう片方の `WO(n)` は `WM(n)` と見える。

応手側は、この `WM(n)` の位置

```text
q = r = n - p - 1
```

に打つ。応手後、局面は

```text
WM(p) + OO(p) + WO(r) + MO(r)
```

になる。これは

```text
T3(p) + T5(r)
```

である。`T3` と `T5` は 9 族負け定理により負けであり、どちらも元の
`A(n,n)` より小さい。したがって、`A(n,n)` は負けである。

これは奇数盤面の中央初手が勝ちであることと整合する。黒が中央に打つと、
白に `A(k,k)` が渡るからである。

## 近均衡型 `A(n,n+1)`

全ての `n >= 1` について、`A(n,n+1)` は手番プレイヤー負けである。

左右対称性により、`A(n+1,n)` も同じである。

### 短い gap に打たれた場合

`WO(n)` の位置 `p` に打たれたとする。合法性より `1 <= p <= n - 2`。
`r = n - p - 1` とおく。

手番交代後、打たれた gap は

```text
WO(p) + MO(r)
```

になり、触られていない `WO(n+1)` は `WM(n+1)` と見える。

応手側は `WM(n+1)` の位置

```text
q = r + 1
```

に打つ。すると応手後は

```text
WM(p) + OO(p) + WO(r + 1) + MO(r)
```

になり、これは

```text
T3(p) + T6(r)
```

である。

### 長い gap に打たれた場合

`WO(n+1)` の位置 `p` に打たれたとする。合法性より `1 <= p <= n - 1`。
`r = n - p` とおく。

手番交代後、打たれた gap は

```text
WO(p) + MO(r)
```

になり、触られていない `WO(n)` は `WM(n)` と見える。

応手側は `WM(n)` の位置

```text
q = r
```

に打つ。すると応手後は

```text
WM(p) + OO(p - 1) + WO(r) + MO(r)
```

になり、これは

```text
T4(p - 1) + T5(r)
```

である。ここで `p = 1` のときは `T4(0) = T0` と読む。

以上より、`A(n,n+1)` からの任意の合法手は、9 族の有限直和へ戻す応手を
持つ。したがって `A(n,n+1)` は手番プレイヤー負けである。

## 残る範囲

`A(n,n)` と `A(n,n+1)` は既存の 9 族定理だけで閉じる。

一方、`|a-b| >= 3` の `A(a,b)` では、同じ応手を使うと

```text
WO(x+d) + MO(x)
```

のような、9 族の `T5`, `T6` より差が大きい境界型が現れる。したがって、
全体分類を証明するには、この差が大きい境界型を扱う新しい補助族が必要に
なる。
