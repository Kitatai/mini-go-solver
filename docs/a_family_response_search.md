# `A(a,b)` 型の応手探索メモ

この文書は、`A(a,b)=WO(a)+WO(b)` の未証明部分について、補助族を探すための
実験結果を整理する。ここに書く観測は証明ではない。

## 全勝ち応手の出力

`solve_gap` には、`A(a,b)` 型の負け局面について全ての勝ち応手を出力する
解析オプションを追加した。

```text
./bin/solve_gap \
  --initial-all-response-sum 20 \
  --initial-all-response-csv /tmp/initial_all_responses_sum20.csv
```

出力される各行は、相手の 1 手、こちらの応手、応手後に相手へ渡る局面を
表す。1 つだけ選ばれた応手を見ると構造を見誤るため、補助族を探すときは
全勝ち応手を見る。

出力を要約するには次を使う。

```text
python3 scripts/analyze_a_family_responses.py /tmp/initial_all_responses_sum20.csv
```

## 応手位置の大まかな分類

`a+b <= 20` の負け `A(a,b)` について見ると、差が大きい場合の応手は
大きく二種類に分かれる。

- 触られていない gap へ打つ応手。
- 相手が打った gap の分割片へ打つ応手。

均衡型 `A(n,n)` と近均衡型 `A(n,n+1)` の証明では、前者だけで十分だった。
しかし、差が大きい場合は後者が必要になる。

特に `A(2,b)` では、`WO(2)` に合法手がないため、相手の手は全て大きい
`WO(b)` に入る。この場合、観測範囲では全ての応手が分割片への応手である。
したがって、`A(2,b)` は一般の `A(a,b)` とは別に扱える可能性が高い。

一方で、`A(2,b)` も 9 族と小さい `A(2,k)` だけで完全には閉じない。
中央から右寄りの手は

```text
T の有限直和
```

または

```text
A(2,k) + T の有限直和
```

に落ちることが多いが、左寄りの手には別の補助族が必要になる。

例えば、相手が大きい `WO(b)` の左寄り、特に正規化座標 `p=1` に打つ場合、
応手後にはしばしば

```text
H0(k) = WM(1) + WO(2) + MO(k)
```

または

```text
H1(k) = WM(1) + OO(1) + WO(2) + MO(k)
```

型が現れる。`WM(1)` と `OO(1)` はどちらも合法手を持たないが、
`WO(2)+MO(k)` 自体は単純な負け族ではない。既存の境界型表では

```text
WO(2) + MO(k): LLWWWLWLWLWLWLWL...
```

のように勝ち負けが混在する。

したがって、この場合も「不活性成分を外して既知の 2-gap 型へ帰着する」
だけでは足りない。不活性成分を含んだままの補助族として扱う必要がある。

`H0`, `H1` を直接計算すると、次のようになる。

```text
H0(k), k=1..32:
LLWWWLWLWLWLWLWLWLWLWLWLWLWLWLWL

H1(k), k=1..32:
LLLWLLLLLLLLLLLLLLLLLLLLLLLLLLLL
```

つまり、`H0(k)` は全体としては負け族ではないが、観測範囲では偶数 `k` が
負けになっている。`H1(k)` は `k=4` だけが勝ちで、それ以外は負けである。

これは `A(2,b)` の証明候補として重要である。左端寄りの相手手に対する
応手は、`b` や局所位置の偶奇によって、負け側の `H0` または `H1` へ
落としている可能性がある。

したがって、次の補助定理候補は次である。

```text
H0(2m) は負けである。
H1(k) は k != 4 で負けである。
```

ただし、これはまだ観測であり証明ではない。特に `H1(4)` の例外が
`A(2,b)` の応手設計で避けられるかを確認する必要がある。

`H0`, `H1` の応手後の形を要約するには次を使う。

```text
./bin/solve_gap \
  --a2-helper-response-max 24 \
  --a2-helper-response-csv /tmp/a2_helper_responses_k24.csv

python3 scripts/analyze_a2_helper_responses.py /tmp/a2_helper_responses_k24.csv
```

この要約から、次のことが分かる。

- `H0(2m)` の一部の相手手は `H0(2m-2)` へ落ちる。
- `H1(k)` の一部の相手手は、`k` の偶奇に応じて `H0(k-1)` または
  `H1(k-2)` へ落ちる。
- しかし全ての相手手が `H0/H1` だけに落ちるわけではない。
  応手後には、例えば `WO(2)+MO(t)`、`MO(s)+MO(t)`、これらに
  `OO(1)` が付いた形などが残る。

したがって、現時点で見えている構造は、`A(2,b)` を単独で証明するものではなく、
少なくとも次の族を同時に扱う必要があることを示している。

```text
A2(k) = WO(2) + WO(k)
H0(k) = WM(1) + WO(2) + MO(k)
H1(k) = WM(1) + OO(1) + WO(2) + MO(k)
K0(s,t) = WO(2) + MO(s) + MO(t)
K1(s,t) = OO(1) + WO(2) + MO(s) + MO(t)
```

`K0`, `K1` は名前を付けただけの作業仮説である。これらも勝ち負けが混在する
可能性が高く、どの偶奇・大小関係の部分だけが帰納に必要なのかを絞る必要がある。
この段階で重要なのは、証明対象が「差の大きい 2-gap 型」から
「短い不活性 gap を含む有限個の補助族の同時帰納」へ移っている点である。

ただし、`K0`, `K1` は完全な 2 変数族ではない可能性が高い。次の出力で
`s,t <= 18` を確認すると、勝敗は `s` 自体ではなく差 `d=t-s` だけで
決まっている。

```text
./bin/solve_gap \
  --a2-k-grid-max 18 \
  --a2-k-grid-csv /tmp/a2_k_grid_18.csv

python3 scripts/analyze_a2_k_grid.py /tmp/a2_k_grid_18.csv
```

観測された列は次である。

```text
K0(s,t), d=t-s=0..17:
LLWWWLWLWLWLWLWLWL

K1(s,t), d=t-s=0..17:
LLLWLLLLLLLLLLLLLL
```

これは、それぞれ `H0(d+1)`, `H1(d+1)` と同じ列である。したがって次の
縮約補題が成り立てば、`K0`, `K1` は新しい主定理ではなく `H0`, `H1` に
吸収できる。

```text
K0(s,t) と H0(t-s+1) は勝敗が一致する。
K1(s,t) と H1(t-s+1) は勝敗が一致する。
```

これはまだ証明ではないが、証明方針としては「同じ `MO` 境界を持つ 2 つの
成分のうち、短い側を差し引く」ような不変性を定式化する必要がある。
この縮約が証明できるなら、`A(2,b)` 周辺の応手後状態はかなり小さい
同時帰納系へ閉じる。

一方で、縮約は「任意の手に対して 1 回の単純な鏡映応手でただちに
`H0/H1` へ落ちる」という形ではない。負けになっている `K0/K1` の応手を
出力するには次を使う。

```text
./bin/solve_gap \
  --a2-k-response-max 12 \
  --a2-k-response-csv /tmp/a2_k_responses_12.csv

python3 scripts/analyze_a2_k_responses.py /tmp/a2_k_responses_12.csv
```

この出力では、短い側と長い側の対応する位置に打たれた場合に小さい
`K0/K1` へ戻る例が多く見える。しかし、内側の手や `WO(2)` 側の手では
単独の `MO(k)` や小さい未分類成分が残る場合がある。したがって、
縮約補題を証明するには、単純な局所相殺だけでなく、9 族成分と小さい
残余成分を含む同時帰納として定式化する必要がある。

この残余成分は、それだけで負けとは限らない。境界型別の単一 gap 勝敗は
次で確認できる。

```text
./bin/solve_gap \
  --gap-type-grid-max 32 \
  --gap-type-grid-csv /tmp/gap_type_grid_32.csv
```

観測列は次である。

```text
WM: LWWWWWWWWWWWWWWWWWWWWWWWWWWWWWWW
WO: LLWWWWWWWWWWWWWWWWWWWWWWWWWWWWWW
MM: WWWWWWWWWWWWWWWWWWWWWWWWWWWWWWWW
MO: LWWWWWWWWWWWWWWWWWWWWWWWWWWWWWWW
OO: LLWLWLWLWLWLWLWLWLWLWLWLWLWLWLWL
```

特に `MO(k)` は `k >= 2` で勝ちになり、`OO(k)` も勝ち負けが混在する。
したがって、`K0/K1` の未分類余りを単独負け成分として片付けることは
できない。必要なのは、余り成分が別の成分と組になったときだけ負けになる
ような補助族である。

## `A(2,b)` が示すこと

`A(2,b)` は、現在見えている規則のうち、端から 3 マス目の初手に対応する。
`N >= 20` の観測規則が真なら、十分大きい `b` で `A(2,b)` は負けで
なければならない。

この族では短い側が完全に不活性なので、問題は次の形に近い。

```text
不活性な WO(2) + 大きい WO(b)
```

相手が大きい gap に打つと、その gap は `WO(p)+MO(r)` に分かれる。
応手はこの `WO(p)` または `MO(r)` の内部に入り、応手後には常に
`WO(2)` を含む 3-gap または 4-gap 状態が残る。

これは、差が大きい `A(a,b)` の一般証明よりも小さい補助族として
切り出せる可能性がある。まず `A(2,b)` を証明できれば、規則の必勝側のうち
端から 3 マス目を確定できる。

## 現時点の示唆

現在の観測からは、次の方針が有望である。

1. `A(2,b)` を独立した補助族として調べる。
2. 次に `A(3,b)`, `A(4,b)` のように、短い側の長さを固定した族を調べる。
3. 各固定短辺族について、全合法手を覆う応手表と、応手後に短辺または総空点数が
   減る帰納構造を探す。
4. ある短辺長以上で共通の応手規則が現れるなら、それを一般の `A(a,b)` の
   証明候補にする。

この方針は、`D_delta` や `B_d` のような差の大きい 2-gap 型を単独で分類する
方針よりも、反例を避けやすい。2-gap 型単独では勝ち負けが混在するためである。
