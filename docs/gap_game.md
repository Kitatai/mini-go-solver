# 空き区間ゲームによる解析方針

このメモは、1 次元 Mini-Go の局面を連続した空き区間の和として扱うための基本的な性質をまとめる。

## 有効局面

ここでは、メモ化つき探索で再帰対象として残す非終局局面を「有効局面」と呼ぶ。

有効局面では、次の手は探索から除外されているものとする。

- 相手に即捕獲手を与える手
- 捕獲手でない端への着手

捕獲手が存在する局面は、その手番プレイヤーの即勝ちとして扱い、子局面を探索しない。

## 定理 1: 相手連への非捕獲接触手は負け手

手番プレイヤーが、相手の連に隣接する空点へ着手したとする。その手が捕獲手でないなら、この手は相手に即捕獲勝ちを与える。

証明:

着手点を `x` とする。`x` が相手の連の隣にあり、その手が捕獲手でないなら、相手の連には `x` 以外の呼吸点が少なくとも 1 つ残る。

一方、`x` に置かれた自分の新しい連は、相手の連がある側を塞がれている。一次元盤面で連の呼吸点になり得るのは左右端の隣だけなので、この手が合法な非自殺手であるためには、反対側に呼吸点を持つ必要がある。したがって、その新しい自分の連は呼吸点を 1 つだけ持つ。

次の相手番では、相手はその唯一の呼吸点に着手できる。この着手は自分の連の呼吸点を 0 にする捕獲手なので、相手が即勝利する。

## 定理 2: 端への非捕獲手は負け手

手番プレイヤーが、盤面の端へ着手したとする。その手が捕獲手でないなら、この手は合法であっても相手に即捕獲勝ちを与える。

証明:

左端 `0` への着手を考える。右端は左右対称で同じである。

着手後、その石を含む自分の連を `C` とする。`C` が右端まで到達しているなら、`C` は左右どちらにも呼吸点を持たない。この手は捕獲手でないので、自殺手であり合法でない。

`C` が右端まで到達していないなら、一次元盤面では `C` の呼吸点は右側に高々 1 つだけである。合法な非自殺手である以上、その右側の 1 点は空点である。したがって、`C` は呼吸点をちょうど 1 つだけ持つ。

次の相手番では、相手はその唯一の呼吸点に着手できる。この着手は `C` の呼吸点を 0 にする捕獲手なので、相手が即勝利する。

## 定理 3: 奇数盤面の中央初手は先手勝ち

盤面長を `N = 2k + 1` とする。先手黒が中央 `k` に初手を置くと、黒は勝つ。

証明:

中央 `k` に関する反転を `r(x) = 2k - x` とする。黒は次の戦略を取る。

1. 黒番で捕獲手があれば、その捕獲手を打って勝つ。
2. そうでなければ、直前の白手 `x` の反転位置 `r(x)` に打つ。

黒の初手後、中央以外の点は反転で 2 点ずつの組に分かれる。黒が上の戦略を続ける限り、各白石には反転位置の黒石が対応し、中央には黒石が 1 つ余分に存在する。

白が端に打った場合、その手が捕獲手でないなら定理 2 により黒に即捕獲勝ちを与える。白が黒連に接触する手を打った場合、その手が捕獲手でないなら定理 1 により黒に即捕獲勝ちを与える。

したがって、黒が即捕獲しない場合に考えるべき白手は、端への非捕獲手でも、黒連への非捕獲接触手でもない。このとき反転位置 `r(x)` は空点であり、同じ局所形を左右反転した位置であるため、黒の反転手も合法な非自殺手である。

もし白が捕獲手を持つ局面が白番で初めて現れるなら、その直前の黒番後の局面は中央を除いて反転対称である。白の捕獲手を反転した手は、直前の黒番で存在した捕獲手に対応する。黒は戦略の第 1 項により捕獲手を優先するため、白が先に捕獲することはない。

捕獲が起きないまま進む場合、中央以外の点は白手と黒の反転応答で 1 組ずつ埋まる。中央には初手の黒石があるため、白が最後の手を打つことはできない。従って、白が合法手を失うか、途中で黒に即捕獲を与える。いずれの場合も黒が勝つ。

## 系: 有効局面の全ての連は 2 呼吸点を持つ

有効局面では、全ての石の連は呼吸点を 2 つ持つ。

証明:

有効局面では、定理 1 により黒石と白石は隣接しない。隣接していれば、その接触を作った手は捕獲手でない相手連への接触手であり、再帰対象から除外される。

また、定理 2 により端に石は存在しない。端に石がある非終局局面は、捕獲手でない端への着手から生じた局面であり、再帰対象から除外される。端への捕獲手はその時点で終局である。

一次元盤面で、端に接しておらず、相手連にも接していない連の左右隣はどちらも空点である。よって、その連は左右に 1 つずつ、合計 2 つの呼吸点を持つ。

## 空き区間への分解

有効局面では、盤面は石の連によって複数の連続した空き区間に分解できる。

空き区間は次の形で表す。

```text
L [m 個の空点] R
```

`L` と `R` は境界であり、次のいずれかである。

- `壁`
- `黒`
- `白`

有効局面の境界石は、区間の外側にも呼吸点を持つ。したがって、区間側の空点を 1 つ埋めただけでは、その境界連は捕獲されない。

この単純化により、空き区間は `Gap(m, L, R)` として扱える。

## 区間手の効果

`Gap(m, L, R)` の内部位置 `i` に手番プレイヤーの石を置くと、区間は左右に分割される。

```text
Gap(i, L, 自分) + Gap(m - i - 1, 自分, R)
```

ただし、次の手は局所的に除外または終局として扱う。

- 捕獲手なら即勝ち。
- 相手境界に接触する非捕獲手は、定理 1 により負け手。
- 壁に接する非捕獲手は、定理 2 により負け手。

## 状態遷移の図

空き区間モデルでは、1 つの局面は単独の `Gap` ではなく、複数の `Gap` の和として表す。

```text
局面 S

  Gap(a, L1, R1) + Gap(b, L2, R2) + ... + Gap(c, Lk, Rk)
        │
        │  任意の 1 区間を選び、その内部位置 i に着手
        ▼
  Gap(i, Lx, 自分) + Gap(mx - i - 1, 自分, Rx)
        │
        │  選ばなかった区間はそのまま残る
        ▼
  Gap(a, L1, R1) + ... +
  Gap(i, Lx, 自分) + Gap(mx - i - 1, 自分, Rx) +
  ... + Gap(c, Lk, Rk)
        │
        │  手番交代により黒白を相対色で反転し、左右反転同型と順序を正規化
        ▼
  正規化された次局面 S'
```

例えば初期盤面で黒が位置 `p` に打った直後の白番は、次の 2 区間の和になる。

```text
壁 [ p 個の空点 ] 黒 [ N - p - 1 個の空点 ] 壁

Gap(p, 壁, 黒) + Gap(N - p - 1, 黒, 壁)
```

その後、白が左側の区間に打つ場合と右側の区間に打つ場合は別の遷移であり、残った反対側の区間も次局面の一部として保持される。

## 必要な値

単独区間の勝敗だけでは、複数区間の和を厳密に合成できない。

全体局面では、手番プレイヤーは任意の区間を選んで着手できる。そのため、ある区間が単独で先手勝ちであっても、相手が別の区間に先着した場合にどう応答するかを同時に扱う必要がある。

したがって、`Gap(m, L, R)` について必要なのは単なる `W/L` ではなく、部分ゲームとして合成可能な値である。

現在の実験コードでは、部分ゲーム値を閉じた形で求める代わりに、複数区間の和そのものを正規化してメモ化する。このため、メモのキーは `Gap(m, L, R)` ではなく、`Gap` の多重集合である。

```text
{ Gap(m1, L1, R1), Gap(m2, L2, R2), ..., Gap(mk, Lk, Rk) }
```

`Gap(i, A, B)` と `Gap(i, B, A)` は左右反転で同型なので同一視できる。また、区間の並び順も勝敗に影響しないため、区間列をソートして同一視できる。それでも、異なる長さと境界を持つ複数区間の組合せが生じるため、単独 `Gap` の種類数より状態数は大きくなる。

候補となる実験方針:

- `Gap(m, L, R)` のゲーム値を小さい `m` から計算する。
- 複数区間の和として初期盤面の探索結果を再現できるか確認する。
- `m` が大きいときの値の周期性または安定性を調べる。
- 周期性が見つかれば、有限個の境界状態に対する帰納法で大きい `N` の結果を証明する。

## 初期盤面との関係

初期盤面で黒が位置 `i` に初手を打つと、盤面は次の 2 つの空き区間の和になる。

```text
Gap(i, 壁, 黒) + Gap(N - i - 1, 黒, 壁)
```

端への初手は定理 2 により負け手である。したがって、初手候補は `1..N-2` に限ってよい。

この 2 区間の和を部分ゲーム値で評価できれば、初手 `i` が先手勝ちかどうかを、全盤面探索より小さい計算で判定できる可能性がある。

## 近端初手に関する補題候補

計算結果では、`N >= 5` における黒の初手 `i = 1` および `i = N - 2` は必敗である。左右対称性により `i = 1` のみを考えればよい。

黒が `1` に置いた直後、白番である。この局面は空き区間として次の和で表される。

```text
Gap(1, 壁, 黒) + Gap(N - 2, 黒, 壁)
```

左の `Gap(1, 壁, 黒)` は白にとって有効な非敗着を持たない。唯一の空点 `0` は端であり、かつ黒石 `1` に隣接している。この手が捕獲手でない限り、定理 1 または定理 2 により黒に即捕獲勝ちを与える。

したがって、`i = 1` が黒の負け手であることは、次の補題から従う。

補題候補:

`m >= 3` に対して、手番プレイヤーから見た `Gap(m, 相手, 壁)` は手番プレイヤー勝ちである。

この補題が成り立てば、`N >= 5` では `m = N - 2 >= 3` なので、黒初手 `1` の直後に白は右側の `Gap(N - 2, 黒, 壁)` で勝ち戦略を持つ。よって黒の初手 `1` は必敗である。右側の `N - 2` も左右対称で同じである。

この補題は、現在の厳密計算では `m <= 43` まで確認されている。これは `N <= 45` の近端初手の結果に対応する。

証明に向けた観察:

- `Gap(m, 相手, 壁)` の左端への手は相手連への非捕獲接触手になりやすく、定理 1 により制限される。
- 右端への手は壁への非捕獲手であり、定理 2 により制限される。
- したがって、手番プレイヤーは両端近傍の危険手を避けつつ、内部に最初の石を置くことで、相手に片側境界の不利を押し付けられる可能性がある。
- 応答解析では、安定領域の多くの勝ち応答が gap の端から距離 `3` 以内に存在しており、補題の証明も局所応答の組合せで表せる可能性がある。

`m <= 30` の全ての勝ち手を列挙すると、各勝ち手は手番交代と正規化の後、常に次の形の 2-gap 負け局面へ移る。

```text
Gap(x, 壁, 相手) + Gap(y, 自分, 相手)
```

ここで `x + y = m - 1` である。したがって、この補題を証明する自然な方針は、`Gap(m, 相手, 壁)` そのものを直接分類することではなく、この境界型 `(壁, 相手) + (自分, 相手)` の 2-gap 局面に対する負け分類を証明することである。

この 2-gap 型は、初期盤面から現れる

```text
Gap(a, 壁, 相手) + Gap(b, 相手, 壁)
```

とは境界条件が異なる。したがって、近端初手の補題と初期盤面全体の分類は、関連しているが同一の 2-gap 分類だけでは扱えない。

さらに `x + y <= 40` の厳密計算では、次の近均衡 2-gap 局面が常に手番プレイヤーの負けであることが確認されている。

```text
Gap(ceil(s / 2), 壁, 相手) + Gap(floor(s / 2), 自分, 相手)
```

ここで `s = x + y >= 2` である。偶数 `s = 2k` では `(k,k)`、奇数 `s = 2k+1` では `(k+1,k)` に対応する。

この近均衡 2-gap 負け補題が全ての `s >= 2` で成り立てば、`Gap(m, 相手, 壁)` の中央手は、相手を `s = m - 1` の近均衡 2-gap 負け局面へ移す。したがって、近端初手の補題はこの 2-gap 負け補題から従う。

この補題について、`s <= 40` の全合法手への応答を列挙すると、`s = 2,3` では手番プレイヤーに合法手が存在しない。`4 <= s <= 40` では全ての合法手に対して勝ち応答が存在し、記録された最短応答の端距離は最大 `4` であった。703 個の合法手のうち 695 個は、応答 gap の端から距離 `2` 以下の着手で応答できる。

したがって、この補題の証明方針は次の形になる。

1. `s = 2,3` を合法手なしの基底ケースとして扱う。
2. `s >= 4` で相手の合法手を分類する。
3. 各分類に対して、端近傍の応答または少数の例外応答を与え、既に負けと分かっているより小さい局面へ移す。

端距離 `2` 以下の応答で処理できない少数の例外は、いずれも相手の手が片側に長さ `3` の gap を作る場合に限られる。したがって、証明では「長さ `3` の side gap を作らない手」と「長さ `3` の side gap を作る手」に分けるのが自然である。後者は、近均衡 2-gap だけで閉じるのではなく、長さ `3` の成分を含む少数の 4-gap 負け型を補助補題として同時に扱う必要がある可能性が高い。

実験的には、この補助型は 2 つの 4-gap 族と 1 つの特殊型に整理できる。4-gap 族は `r <= 18` まで全て手番プレイヤー負けであることが確認されている。したがって、近均衡 2-gap 補題は、これらの補助 4-gap 補題と同時に帰納法で証明するのが有望である。

この段階では、この補題は証明済みの定理ではない。これを定理化するには、`m` に関する帰納法または有限個の局所型への分類が必要である。

## 全体証明へ向けた命題候補

`N <= 45` の厳密計算と 2-gap 解析から、次の分類が成り立つことが観測されている。

初手後の 2-gap 状態

```text
G(a,b) = Gap(a, 壁, 黒) + Gap(b, 黒, 壁)
```

について、`a >= 1`, `b >= 1`, `a + b >= 19` の範囲では、黒初手が負ける場合は次に限られる。

- `a = 1`
- `b = 1`
- `a + b` が偶数、かつ `|a - b| = 2`

この分類が任意の十分大きな `a,b` について証明できれば、初手結果の観測規則が従う。

- 端 `0,N-1` は定理 2 により負け。
- 近端 `1,N-2` は上の `Gap(m, 相手, 壁)` 補題により負け。
- 奇数盤面の中央 `k` は定理 3 により勝ち。
- 奇数盤面の中央隣は `a + b` 偶数かつ `|a-b|=2` の場合に対応し、2-gap 分類により負け。
- それ以外の初手は 2-gap 分類により勝ち。

したがって、残る主要課題は、2-gap 分類を有限個の局所応答型と帰納法で証明することである。
