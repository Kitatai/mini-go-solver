# 9 族負け定理の応手表

この文書は、`nine_family_proof.md` で使う応手表をまとめる。

## 記法

```text
WM(n) = Gap(n, wall, current)
WO(n) = Gap(n, wall, opponent)
MM(n) = Gap(n, current, current)
MO(n) = Gap(n, current, opponent)
OO(n) = Gap(n, opponent, opponent)
```

9 族は次の通りである。各族で `n >= 1` とする。

```text
T0:  WM(1)
T1:  MO(n) + MO(n)
T2:  OO(n) + MM(n)
T3:  OO(n) + WM(n)
T4:  OO(n) + WM(n + 1)
T5:  WO(n) + MO(n)
T6:  WO(n + 1) + MO(n)
T7:  WM(1) + MO(n) + MO(n)
T8:  WM(1) + OO(n) + MM(n)
```

応手表の座標は、手番交代後に正規化された局面での座標である。物理的な
左右が反転している場合は、座標も反転して読む。

ゼロ長の成分は省略する。`T4(0)` は `WM(1)`、すなわち `T0` と読む。

## T1: `MO(n) + MO(n)`

片方の `MO(n)` の位置 `p` に打たれたら、もう片方の `MO(n)` の同じ
位置 `p` に応手する。`r = n - p - 1` とすると、応手後は

```text
OO(p) + MM(p) + MO(r) + MO(r)
```

である。したがって、これは `T2(p) + T1(r)` に分解される。

## T2: `OO(n) + MM(n)`

`MM(n)` の位置 `p` に打たれたら、対応する `OO(n)` 成分に同じ位置で
応手する。応手後は

```text
T2(p) + T2(n - p - 1)
```

である。

`OO(n)` の位置 `p` に打たれたら、対応する `MM(n)` 成分に同じ位置で
応手する。応手後は

```text
T1(p) + T1(n - p - 1)
```

である。

## T3: `OO(n) + WM(n)`

`WM(n)` の位置 `p` に打たれたら、対応する `OO(n)` 成分に

```text
q = min(p, n - 1 - p)
```

で応手する。`r = n - p - 1` とすると、応手後は

```text
p <= r:  T3(p) + T2(r)
p >  r:  T2(r) + T3(p)
```

である。

`OO(n)` の位置 `p` に打たれたら、対応する `WM(n)` 成分の位置 `p` に
応手する。応手後は

```text
T5(p) + T1(n - p - 1)
```

である。

## T4: `OO(n) + WM(n + 1)`

`OO(n)` の位置 `p` に打たれたら、対応する `WM(n + 1)` 成分に

```text
q = n - p
```

で応手する。応手後は

```text
T1(p) + T6(n - p - 1)
```

である。

`WM(n + 1)` の位置 `p` に打たれたら、対応する `OO(n)` 成分に

```text
q = p - 1    if p <= floor(n / 2)
q = n - p    if p >  floor(n / 2)
```

で応手する。応手後は

```text
T4(p - 1) + T2(n - p)
```

である。

## T5: `WO(n) + MO(n)`

`WO(n)` の位置 `p` に打たれたら、対応する `MO(n)` 成分の位置 `p` に
応手する。応手後は

```text
T3(p) + T1(n - p - 1)
```

である。

`MO(n)` の位置 `p` に打たれたら、対応する `WO(n)` 成分に

```text
q = n - 1 - p
```

で応手する。応手後は

```text
T2(p) + T5(n - p - 1)
```

である。

## T6: `WO(n + 1) + MO(n)`

`MO(n)` の位置 `p` に打たれたら、対応する `WO(n + 1)` 成分に

```text
q = n - p
```

で応手する。応手後は

```text
T2(p) + T6(n - p - 1)
```

である。

`WO(n + 1)` の位置 `p` に打たれたら、対応する `MO(n)` 成分に

```text
q = p - 1
```

で応手する。応手後は

```text
T4(p - 1) + T1(n - p)
```

である。

## T7: `WM(1) + MO(n) + MO(n)`

`WM(1)` には合法手がない。`n = 1` なら全体にも合法手がない。

`n >= 2` で `MO(n)` の位置 `p` に打たれたら、もう片方の `MO(n)` の
同じ位置 `p` に応手する。`r = n - p - 1` とすると、応手後は

```text
T0 + OO(p) + MM(p) + MO(r) + MO(r)
```

である。したがって、

```text
p = 0:  T7(r)
p > 0:  T8(p) + T1(r)
```

に分解される。

## T8: `WM(1) + OO(n) + MM(n)`

`WM(1)` には合法手がない。

`MM(n)` の位置 `p` に打たれたら、対応する `OO(n)` 成分の位置 `p` に
応手する。`r = n - p - 1` とすると、応手後は

```text
T0 + OO(p) + MM(p) + OO(r) + MM(r)
```

である。これは境界の場合を含めて `T8(p) + T2(r)` 型に分解される。
ただし `p = 0` のときは `T8(r)`、`r = 0` のときは `T8(p)`、両方が
ゼロなら `T0` である。

`OO(n)` の位置 `p` に打たれたら、対応する `MM(n)` 成分の位置 `p` に
応手する。合法性より `p > 0` かつ `r = n - p - 1 > 0` であり、応手後は

```text
T7(p) + T1(r)
```

である。

## 閉包性

全ての応手は合法であり、応手後の各成分は元の 9 族成分より小さい。
したがって、有限直和に対する帰納法で 9 族負け定理が従う。
