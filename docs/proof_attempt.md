# 全体分類に向けた未解決課題

この文書は、探索で観測されている初手分類のうち、まだ証明されていない
「勝ち手側」を証明するための現在の作業地図である。証明済みの定理は
`theory_overview.md` にまとめる。

## 目標

初手 `i` の後、相手番の gap 局面は

```text
A(i, N - i - 1) = WO(i) + WO(N - i - 1)
```

である。したがって、初手 `i` が先手勝ちであることは、この `A` 局面が
相手番負けであることと同値である。

観測されている `N >= 20` の分類を証明するには、証明済みの負け手に
対応する例外を除いて、十分広い範囲の `A(a,b)` が負けであることを
示す必要がある。

## 証明済みの範囲

既に次は証明済みである。

- `A(n,n)` は負けである。
- `A(n,n+1)` は負けである。
- 近端初手の負けに対応する `A(1,b)` は、相手が勝ちにできる。
- 奇数中央隣の負けに対応する `A(k-1,k+1)` は、相手が `R(k-1)` へ
  落とすことで勝ちにできる。

詳細は `a_family_partial_proof.md`, `center_adjacent_proof.md`,
`nine_family_proof.md` を参照する。

## 現在の主障害

残る本質的な範囲は、差が大きい

```text
A(a,b) = WO(a) + WO(b),   |a-b| >= 3
```

である。片方の `WO` に打たれると、手番交代後に

```text
WM(a) + WO(p) + MO(r)
```

のような 3-gap 局面が現れる。均衡型や近均衡型では、この後の応手で
9 族の有限直和へ戻る。しかし差が大きい場合は、単純な長さ合わせだけでは
9 族へ戻らず、補助族が必要になる。

以前は

```text
D_delta(p) = WM(p) + OO(p + delta)
```

や

```text
B_delta(p) = WO(p + delta) + MO(p)
```

を主候補として調べた。しかしこれらは勝ち負けが混在するため、単独の
負け族としては使えない。現在の方針は、差の大きい 2-gap 型を直接
分類するのではなく、初手後の短い不活性 gap を含む補助族へ分解することである。

## `A(2,b)` から見える構造

端から 3 マス目の初手に対応する `A(2,b)` は、残りの証明の最小の
非自明ケースである。`WO(2)` には合法手がないため、相手の手は必ず
大きい `WO(b)` に入る。

全勝ち応手の観測から、次の補助族が現れる。

```text
H0(k) = WM(1) + WO(2) + MO(k)
H1(k) = WM(1) + OO(1) + WO(2) + MO(k)
```

さらに `H0/H1` の応手後には

```text
K0(s,t) = WO(2) + MO(s) + MO(t)
K1(s,t) = OO(1) + WO(2) + MO(s) + MO(t)
```

が現れる。ただし観測上、`K0/K1` は 2 変数族として振る舞わず、勝敗が
差 `d=t-s` だけで決まっている。

```text
K0(s,t) は H0(t-s+1) と同じ勝敗を持つように見える。
K1(s,t) は H1(t-s+1) と同じ勝敗を持つように見える。
```

この縮約が証明できれば、`A(2,b)` 周辺は `A2`, `H0`, `H1` を中心とする
小さな同時帰納系へ閉じる可能性が高い。

ただし、`K0/K1` の応手後状態は、9 族を外すだけでは完全には閉じない。
未分類部分には、現在手番の合法手を持たない短い gap と、単一の `MO(k)` や
`MM(k)` が組になった状態が多く現れる。`MO(k)` は単独では負けではないため、
これらを単純に削除することはできない。

したがって、現在の見方では `K0/K1` の縮約は

```text
短い側の成分を差し引いて H0/H1 に同一視する
```

という単純な不変性ではなく、

```text
不活性成分を含む有限個の補助族が、2 手応手後に小さい同型へ戻る
```

という同時帰納として証明する必要がある。

ここで、次の限定的な不活性成分補題は証明済みとして使える。

```text
I を現在手番が合法手を持たない成分の有限和とする。
S が「任意の着手に対して同じ S 型の小さい局面、または既知の負け和へ
2 手応手で戻る」形で負けと証明されているなら、S + I も負けである。
```

理由は、現在手番は初手で `I` に打てないため必ず `S` 側へ打つ。応手側は
`S` の証明に従って `S` 側へ応手する。2 手後には、触られていない `I` の
相対境界が元に戻る。したがって帰納で扱う局面は再び `S + I` 型になる。
特に `S` が空の場合は、現在手番に合法手がないので負けである。

この補題は、不活性成分を任意に消してよいという主張ではない。相手番では
その成分に合法手が生じる場合があるため、応手を 2 手単位で指定できる
負け証明と組み合わせる場合に限って使う。

全勝ち応手を出して、各相手手ごとに証明しやすい応手を選ぶと、`K0/K1` の
一部は次の型へ落ちる。

```text
T の有限直和 + 不活性成分
小さい K0/K1 + T
```

これは縮約補題に近い。ただし、差が大きい場合にはまだ

```text
MO(k) + 不活性成分
MM(k) + 不活性成分
複数の active gap + 不活性成分
```

が残る。したがって次の段階では、`K0/K1` だけで閉じようとするのではなく、
これらの残余型を名前付き補助族として追加し、全合法手が
「小さい補助族 + 証明済み負け和」へ落ちるかを調べる。

単一 active gap と短い不活性成分から、次の候補族が得られている。

```text
Q0(k) = WO(2) + MO(k)  または  OO(1) + MO(k)
Q1(k) = OO(2) + MO(k)
Q2(k) = I + OO(k) ただし I は WO(2), OO(1), OO(2) のいずれか
```

観測範囲では `Q0(1)`, `Q0(2)`, `Q0(2m)` (`m>=3`), `Q1(k)` (`k!=4`),
`Q2(k)` が負けである。`Q0` は勝ち負けが混在するため、偶奇と小さい例外を
含めて定式化する必要がある。

ただし、`H1(k)` は `Q0(k)` だけでは説明できない。`H1` には `WO(2)` と
`OO(1)` の両方が含まれるため、複数不活性成分を持つ族として別に扱う。

## 次に証明すべき補題候補

現在の最優先候補は次である。

```text
K0(s,t) と H0(t-s+1) の勝敗一致。
K1(s,t) と H1(t-s+1) の勝敗一致。
H0(2m) は負けである。
H1(k) は k != 4 で負けである。
Q0(1), Q0(2), Q0(2m) は負けである。
Q1(k) は k != 4 で負けである。
Q2(k) は負けである。
A(2,b) は b >= 5 で負けである。
```

この順序は重要である。`A(2,b)` を直接証明しようとすると応手後状態が
広がるが、先に `K0/K1` の縮約を証明できれば、必要な補助族の数を
抑えられる。ただし、その縮約自体にも不活性成分を含む補助族が必要になる
可能性が高い。

## 検査方針

候補補題は、まず厳密探索で小さい反例を探す。その後、応手規則を
機械可読な形に落とし、各合法手について次を確認する。

- 指定された応手が合法である。
- 2 手後の局面が既知の負け族、またはより小さい補助族の有限直和になる。
- 帰納に使うパラメータが必ず減少する。

この形式に落とせない観測は、証明ではなく探索上の手がかりとして扱う。
