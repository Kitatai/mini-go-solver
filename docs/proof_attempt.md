# 全体分類に向けた整理

この文書は、探索結果から見えている初手分類を証明するために、残っている
課題を整理する。

証明済みの定理は `theory_overview.md` にまとめる。ここでは、まだ証明が
完了していない「残りの初手が勝ち手である」方向だけを扱う。

## 観測されている分類

探索結果では、十分大きい `N`、具体的には現在の計算範囲では `N >= 20`
において、初手の勝敗は次の形に安定している。

- `N` が偶数のとき、端 2 マス `0, 1, N-2, N-1` が先手負けで、
  それ以外は先手勝ち。
- `N` が奇数のとき、端 2 マスに加えて、中央の左右隣
  `(N-3)/2, (N+1)/2` が先手負けで、それ以外は先手勝ち。

この分類のうち、負け手側はかなり証明できている。

- 端 `0, N-1`: 端への非捕獲手は負け手。
- 近端 `1, N-2`: 9 族負け定理から負け手。
- 奇数中央隣 `(N-3)/2, (N+1)/2`: `R(a)` 補題から負け手。

未解決なのは、上記以外の初手が全て勝ち手であることの証明である。
このうち、`A(n,n)` と `A(n,n+1)` は `a_family_partial_proof.md` で
証明済みである。

## 初手後の 2-gap 表現

初手 `i` の後、相手番の局面は

```text
A(i, N - i - 1) = WO(i) + WO(N - i - 1)
```

である。したがって、初手 `i` が先手勝ちであることは、この `A` 局面が
相手番負けであることと同値である。

この言い換えにより、全体分類の残りは次の問題になる。

```text
証明済みの負け手に対応する例外を除き、
A(a,b) = WO(a) + WO(b) は手番プレイヤー負けである。
```

## 証明済みの例外

近端初手の負けは、`A(1, b)` が相手番勝ちであることに対応する。
実際、相手は大きい gap に中央寄りの手を打ち、`WM(1) + P(s)` 型の
負け局面を渡せる。

奇数中央隣の負けは、`A(k-1, k+1)` が相手番勝ちであることに対応する。
相手は反転位置に打ち、`R(k-1)` を渡せる。

奇数中央の勝ちは、`A(k,k)` が相手番負けであることに対応する。これは
中央初手後の反転戦略から従う。

## 残る証明目標

残っているのは、主に次の形である。

```text
A(a,b) = WO(a) + WO(b)
```

について、

- `a,b >= 2`
- `a,b` が近端例外ではない
- `|a-b| != 2` または `a+b` が奇数

の範囲で、手番プレイヤー負けを示すことである。

これは、これまで証明した「特定初手が負け手である」方向とは逆である。
つまり、相手の全ての手に対して応手し、`A` 型または既知の負け族の有限
直和へ戻す必要がある。

## 次に探すべき構造

9 族定理と `R(a)` 補題はいずれも、次の形で閉じている。

1. 相手が片方の成分に打つ。
2. 触られていない対応成分に応手する。
3. 応手後、より小さい同型の負け族と、9 族の有限直和に分解される。

`A(a,b)` の残りも同様に、応手後に小さい `A` 型または既知の補助族へ
落ちる可能性がある。次の段階では、`A(a,b)` からの全合法手に対して、
どの応手がどの型へ落ちるかを分類する。

特に、`a` と `b` の差、偶奇、近端からの距離が応手型を分ける可能性が
高い。観測された例外が `a=1`, `b=1`, そして `a+b` 偶数かつ
`|a-b|=2` に集中しているため、これらの条件が閉包性の境界になっている
かを調べる。

均衡型 `A(n,n)` と近均衡型 `A(n,n+1)` では、応手後に既存の 9 族だけが
現れるため証明が閉じる。`|a-b| >= 3` では、応手後に

```text
WO(x+d) + MO(x)
```

のような差の大きい境界型が現れる。したがって、次の主な課題はこの境界型
を含む新しい補助族を見つけることである。

## 差が大きい場合に現れる形

`A(a,b)` で `b >= a + 3` とする。短い方または長い方の `WO` gap に
打たれると、手番交代後には一般に

```text
WM(a) + WO(p) + MO(r)
```

型の 3-gap 局面が現れる。ここで `WM(a)` は、触られていない元の gap が
手番交代で見え方を変えたものであり、`WO(p) + MO(r)` は打たれた gap が
分割されたものである。

`A(n,n)` や `A(n,n+1)` では、この 3-gap 局面への応手後に 9 族だけが
残る。しかし差が 3 以上あると、応手後に

```text
WO(r+d) + MO(r)
OO(p+d) + WM(p)
```

のような、9 族の近均衡範囲から外れた成分が残る。

したがって、残りの証明では次のどちらかが必要になる。

1. 差の大きい境界型 `WO(x+d)+MO(x)` などを含む新しい負け族を定義する。
2. あるいは、応手位置を変えて、これらの差の大きい成分をさらに別の既知族
   または新補助族へ分解できることを示す。

既存の 9 族、`R(a)`、および `A(n,n)`, `A(n,n+1)` だけでは、差が大きい
`A(a,b)` 全体を閉じるには足りない。
