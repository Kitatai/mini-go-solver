# 証明検査の方針

証明は最終的には人間が読める形で記述する。ただし、応手位置や境界型の
取り違えは文章だけでは見落としやすい。そのため、証明を次の層に分けて
検査する。

## 層 1: 厳密探索との照合

通常の探索器は、局面の勝敗を定義そのものから計算する。これは証明では
ないが、候補定理や補助族の反例を探すために使う。

この層では、次を確認する。

- 計算済みの初手表と gap-sum モデルが一致していること。
- 新しい補助族に小さい反例がないか。
- 反例がある場合、その形が既存の分類とどう関係するか。

## 層 2: 応手式の機械検査

証明で使う応手規則は、局所遷移として機械的に検査できる。
`scripts/check_gap_proof_rules.py` は、現在文書化されている次の応手式を
有界範囲で検査する。

- `A(n,n)` の応手式。
- `A(n,n+1)` の短い gap・長い gap それぞれの応手式。
- `R(a)=MO(1)+WM(a)+WO(a)` の応手式。

この検査では、各合法手について次を確認する。

- 文書に書かれた応手位置が存在すること。
- 応手が合法手であること。
- 2 手後の局面が、文書に書かれた負け族の直和と一致すること。

実行例:

```text
make proof-check
```

この検査は有界検査なので、それだけで全ての `n` に対する証明にはならない。
しかし、応手式は線形な添字式で書かれているため、添字のずれ、境界条件の
抜け、手番交代後の境界名の取り違えを検出する役割を持つ。

## 層 3: 形式化された応手規則

今後、証明が大きくなる場合は、応手規則を文章から分離し、機械可読な形に
する。必要な要素は次である。

- gap 型: `WM(n)`, `WO(n)`, `MM(n)`, `MO(n)`, `OO(n)`。
- パラメータ条件: `n >= 1`, `1 <= p <= n-2` など。
- 着手対象: どの成分のどの座標に打つか。
- 応手対象: 手番交代後に見えるどの成分のどの座標に打つか。
- 結果: 2 手後に得られる負け族の直和。
- 減少量: 帰納法で使う主パラメータまたは空点数が小さくなること。

この形式を検査できれば、文章の証明は「なぜこの形式化された規則で帰納法が
閉じるか」を説明する役割に集中できる。

## 層 4: 帰納閉包の検査

最終的に必要なのは、各補助族について次を示すことである。

```text
任意の合法手に対し、指定された応手が存在し、
2 手後の局面が既知の負け族、またはより小さい同じ補助族の直和になる。
```

この条件が機械的に検査できれば、証明の誤りは主に次の二つに限定される。

- 補助族の定義そのものが狙った局面を覆っていない。
- 減少順序が本当に整礎であることの説明が不足している。

したがって、今後の補助族探索では、単に勝敗表を見るだけでなく、
「全合法手を覆う応手表」と「減少する帰納パラメータ」を同時に探す。
