# Mini-Go ルール

## 概要

Mini-Go は、囲碁のルールを簡略化した 1 次元盤面上の二人零和有限確定完全情報ゲームである。

盤面は `1 x N` の直線状に並んだマス列で、黒が先手、白が後手として交互に着手する。

## 盤面

各マスは次のいずれかの状態を持つ。

- `0`: 空点
- `+1`: 黒石
- `-1`: 白石

盤面の位置は、左端から `0, 1, 2, ... , N - 1` のインデックスで表せる。

初期盤面では、すべてのマスが空点である。

## 連と呼吸点

同じ色の石が隣接して連続している部分を「連」として扱う。

一次元盤面なので、ある連の呼吸点は、その連の左右に隣接する空点である。盤面外は呼吸点ではない。

例として、長さ `N` の盤面で黒石の連が区間 `[l, r]` にある場合、呼吸点になり得るのは次の位置である。

- `l - 1` が盤面内かつ空点なら呼吸点
- `r + 1` が盤面内かつ空点なら呼吸点

## 手番

黒番から開始し、以後は黒と白が交互に手番プレイヤーとなる。

## 捕獲手

捕獲手とは、空点に自分の石を置いた結果、相手の連の呼吸点が 0 になる手である。

## 自殺手

自殺手とは、自分の石を置いた結果、その石を含む自分の連の呼吸点が 0 になる手である。

## 合法手

次の条件を満たす着手を合法手とする。

1. 着手先が空点である。
2. 捕獲手である、または自殺手ではない。

手番プレイヤーは、合法手を 1 手着手する。

## 勝利条件

次のいずれかを満たすプレイヤーを勝者とする。

- 捕獲手を着手したプレイヤー。
- 相手の手番で相手に合法手がないプレイヤー。
