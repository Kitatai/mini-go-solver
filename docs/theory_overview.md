# 理論の全体像

この文書は、1 次元 Mini-Go の解析で現在証明できていることと、
まだ未解決のことを整理する。

## 現在の到達点

探索結果から観測された規則のうち、次の部分は証明できている。

1. 端への初手 `i = 0, N - 1` は負け手である。
2. 近端への初手 `i = 1, N - 2` は、`N >= 5` で負け手である。
3. 奇数盤面の中央初手 `i = (N - 1) / 2` は勝ち手である。
4. 奇数盤面の中央隣初手 `i = (N - 3) / 2, (N + 1) / 2` は、`N >= 5` で負け手である。

したがって、観測されている `N >= 20` の分類のうち、負け手として
現れる主要な位置は証明済みである。

未解決なのは逆向き、つまり「それ以外の初手がすべて勝ち手である」
ことの証明である。

## 基本方針

非終局の有効局面では、次の 2 種類の手は再帰探索から除外できる。

- 相手連に隣接する非捕獲手。
- 端への非捕獲手。

どちらも相手に即捕獲手を与えるため、勝ち手にならない。

この簡約後、局面は連続した空き区間の和として扱える。空き区間は

```text
Gap(m, L, R)
```

で表す。`m` は空点数、`L, R` は左右の境界で、`wall`,
`current`, `opponent` のいずれかである。

この空き区間ゲームで構造的な負け局面族を見つけ、任意の手に対する
応手を明示して、より小さい同型の負け局面へ戻す。これが現在の証明の
中心である。

## 証明済みの負け手

### 端

端に置かれた石を含む連は、盤面外側に呼吸点を持てない。非捕獲手で
あれば、その連は高々 1 つの呼吸点しか持たず、相手が次にそこへ打つ
ことで捕獲できる。したがって、端への非捕獲手は負け手である。

### 近端

近端 `i = 1` に初手を打つと、相手は大きい方の空き区間に中央寄りの
応手を打ち、手番プレイヤーへ

```text
WM(1) + P(s)
```

型の局面を渡す。ここで `P(s)` は近均衡 2-gap 局面であり、9 族負け
定理から負けである。`WM(1)` も 9 族定理の有限直和に含めて扱うため、
端側の 1 マスを捨てていない点が重要である。

### 奇数中央

奇数盤面の中央初手は、中央反転に対する鏡映戦略で勝ちである。相手が
捕獲手を作るなら、その反転手は直前に自分にも存在していた捕獲手に
対応するため、相手が先に捕獲することはできない。

### 奇数中央隣

`N = 2k + 1` で初手が `k - 1` のとき、相手は反転位置 `k + 1` に
応手する。すると手番プレイヤーは

```text
R(k - 1) = MO(1) + WM(k - 1) + WO(k - 1)
```

を受け取る。`R(a)` は全て負けであることを帰納法で示せるため、中央隣
初手は負け手である。

## 残る課題

初手 `i` の後、相手番の局面は

```text
A(i, N - i - 1) = WO(i) + WO(N - i - 1)
```

である。したがって、初手 `i` が勝ち手であることは、この `A` 局面が
相手にとって負けであることと同値である。

観測されている `N >= 20` の分類を完全に証明するには、証明済みの負け手
を除いた範囲で `A(a,b)` が負けであることを示す必要がある。

このうち `A(n,n)` と `A(n,n+1)` は、9 族負け定理だけで証明できる。
残る本質的な難所は、`|a-b| >= 3` の `A(a,b)` である。
